# Team Code 06 — Shell: windows, sidebar, views Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build everything a Team Code window is made of apart from the Board, the task page and the canvas: the start screen and first-run onboarding, window chrome, the tab strip, the sidebar (single-project icon strip and workspace multi-root or rail), free-form split views with the task picker, the attention strip, the command palette, the keyboard registry, Dock badge and notifications, and the app and project settings screens.

**Architecture:** Two window-level module stores, `src/features/shell/store.ts` (which window this is, active tab, sidebar, project focus) and `src/features/views/store.ts` (views, layouts, focused pane), plus two shared read stores in `src/lib/stores/` (`projectsStore`, `tasksStore`) fed by Plan 03's commands and events. Layout editing is pure TypeScript over the contracts' `LayoutNode` (`src/features/views/layout.ts`) so a split or close responds instantly; the result is persisted through `views_update_layout`. One keyboard registry, `src/lib/keyboard.ts`, owns every ⌘ chord and is tested for conflicts with the terminal. Every component composes Plan 02's primitives; no raw controls.

**Tech Stack:** React 19, TypeScript 5 strict, Vite, Tailwind v4 semantic tokens, `useSyncExternalStore` stores via Plan 01's `createStore`, cmdk through Plan 02's `Combobox`, dnd-kit (`@dnd-kit/core`, `@dnd-kit/sortable`) for tab reorder and pane moves, Sonner via Plan 02's `Toast`, `@tauri-apps/api` (window, event), `@tauri-apps/plugin-notification`, `@tauri-apps/plugin-dialog`, Vitest + `@testing-library/react` + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-24-team-code-design.md` §4.4, §10.1, §10.4, §10.5, §13 (app and project rows), §11.1–11.3 (as consumed). Contracts: `docs/superpowers/plans/2026-10-24-team-code-00-overview-and-contracts.md`.

## Global Constraints

- Tauri 2; Rust stable; Node 22; React 19; TypeScript 5.x strict; Vite; Tailwind v4 via `@tailwindcss/vite`, no `tailwind.config` (§3, LiveSpec convention).
- Three layers: `crates/teamcode-core` never depends on Tauri; `src-tauri` stays thin; the webview has no state library and uses module stores read with `useSyncExternalStore` (§3, §14).
- IPC types are generated by `tauri-specta` into `src/lib/bindings.ts`; hand-written mirrors are forbidden (§15.1).
- Raw `<input>`, `<select>`, `<textarea>`, `<button>`, `<dialog>` appear only under `src/components/ui/`; hex colours and inline colour styles appear only in the theme file. ESLint fails the build otherwise (§15.3).
- Semantic Tailwind tokens only: `bg-page`, `bg-bar`, `bg-well`, `bg-card`, `border-line`, `text-ink`, `text-mute`, `text-accent`, `text-ok`, `text-warn`, `text-bad`, plus `stage-spec|plan|build|review|test|commit|done` (§11.1).
- Every id that becomes a path matches `^[a-z]+-[0-9a-f-]{1,40}$` before use (§14).
- Model and agent output renders only through `MiniMarkdown` or xterm, never `innerHTML` (§14).
- The app never commits, merges, rebases, pushes or deletes branches on its own; the Commit button exists only when "Team Code may commit" is on, default off (§6.6).
- Nothing a user triggers takes longer than 250 ms to respond; `prefers-reduced-motion` turns springs into 150 ms eases and stops loops (§11.3).
- File size budgets: component under about 200 lines, store under 300, Rust module under 500 (§15.1).
- Naming: components `PascalCase.tsx`, lib and stores `camelCase.ts`, Rust `snake_case`; IPC commands `domain_verb` in snake_case; events `kebab-case` (§15.1, this document).
- Commits follow Conventional Commits (§15.4). Every task ends with the quality gates in §15.4 passing for the code it touched.
- A feature imports another feature only through its `index.ts`, never its store or internals (§15.1).
- The app claims only the ⌘ chords in §10.5; the terminal receives every other key (§10.5).

## Review Focus

1. A pane that references a task which no longer exists or is archived when the view is restored at relaunch: the pane shows a placeholder with "Pick another task", nothing throws, and the sibling panes still re-attach. Pinned in Task 7.
2. ⌘W in a view's last pane: the pane empties to the picker rather than disappearing or closing the window; the view keeps one leaf. Pinned in Task 5 and Task 6.
3. Keys while an xterm pane has focus: only ⌘ chords from the map are claimed; ⌃` is claimed only when a Spec page, not a terminal, has focus; ⌘C and ⌘V never reach the registry. Pinned in Task 1.
4. A storm of `task-changed` events for one task: exactly one toast or OS notification per transition into needs-you, none for needs-you → needs-you updates, and only one window of several sends the OS notification and sets the Dock badge. Pinned in Task 16.
5. ⌘1 to ⌘9 beyond the number of tabs or projects, and the same key pressed twice in a workspace: out-of-range is ignored, the second press clears the focus. Pinned in Task 4.

// src/lib/keyboard.test.ts
import { describe, it, expect } from 'vitest'
import { KEYMAP, TERMINAL_RESERVED, parseChord, chordEquals, matchShortcut, registerHandler } from './keyboard'

const ev = (key: string, m: Partial<KeyboardEventInit> = {}) =>
  new KeyboardEvent('keydown', { key, metaKey: false, shiftKey: false, altKey: false, ctrlKey: false, ...m })

describe('keyboard registry', () => {
  it('parses every label in the map', () => {
    for (const { chords } of Object.values(KEYMAP)) for (const c of chords) expect(() => parseChord(c)).not.toThrow()
    expect(parseChord('⌘⇧[')).toEqual({ key: '[', meta: true, shift: true, alt: false, ctrl: false })
    expect(parseChord('⌘⏎')).toEqual({ key: 'Enter', meta: true, shift: false, alt: false, ctrl: false })
    expect(parseChord('⌘⌥←').key).toBe('ArrowLeft')
  })
  it('claims only ⌘ chords except the Spec strip toggle', () => {
    for (const [id, { chords, scope }] of Object.entries(KEYMAP)) for (const c of chords) {
      const chord = parseChord(c)
      if (id === 'terminalStrip.toggle') { expect(chord.ctrl).toBe(true); expect(scope).toBe('spec-page') }
      else expect(chord.meta).toBe(true)
    }
  })
  it('has no duplicate chords and none reserved by the terminal', () => {
    const all = Object.values(KEYMAP).flatMap((k) => k.chords.map(parseChord))
    for (let i = 0; i < all.length; i++) for (let j = i + 1; j < all.length; j++) expect(chordEquals(all[i], all[j])).toBe(false)
    for (const r of TERMINAL_RESERVED.map(parseChord)) for (const c of all) expect(chordEquals(r, c)).toBe(false)
  })
  it('matches ⌘3 as tab.nth with digit 3 and ⌘⇧] as view.next', () => {
    expect(matchShortcut(ev('3', { metaKey: true }), { scope: 'global', terminalFocused: false })).toEqual({ id: 'tab.nth', digit: 3 })
    expect(matchShortcut(ev(']', { metaKey: true, shiftKey: true }), { scope: 'global', terminalFocused: false })).toEqual({ id: 'view.next' })
  })
  it('never claims ⌃` while a terminal is focused, and never claims ⌘C or plain keys', () => {
    expect(matchShortcut(ev('`', { ctrlKey: true }), { scope: 'spec-page', terminalFocused: true })).toBeNull()
    expect(matchShortcut(ev('`', { ctrlKey: true }), { scope: 'spec-page', terminalFocused: false })).toEqual({ id: 'terminalStrip.toggle' })
    expect(matchShortcut(ev('c', { metaKey: true }), { scope: 'pane', terminalFocused: true })).toBeNull()
    expect(matchShortcut(ev('a'), { scope: 'pane', terminalFocused: true })).toBeNull()
  })
  it('does not match pane-scoped chords in global scope', () => {
    expect(matchShortcut(ev('d', { metaKey: true }), { scope: 'global', terminalFocused: false })).toBeNull()
    expect(matchShortcut(ev('d', { metaKey: true }), { scope: 'pane', terminalFocused: true })).toEqual({ id: 'pane.splitRight' })
  })
  it('calls registered handlers and unregisters', () => {
    const seen: number[] = []
    const off = registerHandler('tab.nth', ({ digit }) => seen.push(digit!))
    matchShortcut(ev('2', { metaKey: true }), { scope: 'global', terminalFocused: false }, { dispatch: true })
    off()
    matchShortcut(ev('2', { metaKey: true }), { scope: 'global', terminalFocused: false }, { dispatch: true })
    expect(seen).toEqual([2])
  })
})
