# CLAUDE.md

Guidance for Claude Code and every other agent working in this repository. Keep it under 150 lines; details live in
`ARCHITECTURE.md`, `.claude/rules/` and `docs/adr/`.

## What this is

Team Code is a macOS desktop app (Tauri 2) for one developer running several AI coding agents across several projects.
A window holds a project or a workspace of linked projects; each project has a Kanban board of tasks, and each task owns
a real terminal session (Claude Code, Codex or a shell) and a markdown memory folder, moving Spec → Plan → Build → Review
→ Test → Commit → Done.

## Layers

- `crates/teamcode-core` — domain, pipeline, SQLite, memory, git. Plain Rust with tests. **Never depends on Tauri.**
- `src-tauri` — the thin shell: `AppState`, Rust-created windows (`w-<n>`), commands and events exported by tauri-specta.
- `src/` — React 19 webview. **No state library**: module stores built with `createStore` and read with
  `useSyncExternalStore`.
- `crates/livespec-core` is copied from LiveSpec unchanged; adapt it from `teamcode-core` or the shell, never edit it.

## Commands

Use Node 22 (`nvm use 22`). A fresh clone, or a checkout whose `package-lock.json` moved (after a merge or a
rebase), runs these two first; nothing installs them for you (there is no `postinstall`):

```sh
npm ci                                             # exact lockfile install; also installs the lefthook hook
PLAYWRIGHT_BROWSERS_PATH=0 npx playwright install webkit   # WebKit into node_modules, for npm run e2e
```

A stale `node_modules` shows as hundreds of `Cannot find module` errors in `npm run typecheck` and a pre-commit hook
that refuses every commit; run `npm ci` again.

```sh
npm run tauri dev                                  # the app
npm run dev                                        # Vite alone; every invoke fails outside Tauri
npm run typecheck                                  # tsc --noEmit
npm run lint                                       # ESLint (with the Team Code rules) and Prettier --check
npx vitest run                                     # webview and lint-rule tests
cargo test --workspace                             # Rust tests
cargo clippy --workspace --all-targets -- -D warnings
npm run bindings                                   # regenerate src/lib/bindings.ts from Rust
npm run bindings:check                             # fails when bindings.ts is stale (CI runs it)
npm run format                                     # Prettier --write
npm run build                                      # tsc + vite build
npm run e2e                                        # Playwright smoke suite (needs the WebKit install above)
```

## Rules that lint enforces

- Raw `<input>`, `<select>`, `<textarea>`, `<button>`, `<dialog>` only under `src/components/ui/`; everything else
  composes the primitives (`teamcode/no-raw-controls`).
- Hex colours and inline colour styles only in `src/styles.css`; use semantic classes (`teamcode/no-colour-literals`).
- IPC only through `src/lib/bindings.ts`; never import `invoke` or `listen` from `@tauri-apps/api` directly
  (`teamcode/no-manual-ipc`).
- A feature imports another feature only through its `index.ts` (`teamcode/feature-boundaries`).

## Generated bindings

`src/lib/bindings.ts` is generated by tauri-specta and committed. Edit the Rust types or commands, run
`npm run bindings`, commit the result. CI fails when it is stale. Hand-written mirrors of Rust types are forbidden
(ADR 0001).

## Naming

Components `PascalCase.tsx`, lib and stores `camelCase.ts`, Rust `snake_case`; IPC commands `domain_verb` in
snake_case; events `kebab-case`. Serde: no `rename_all`; fields stay `snake_case`, variants keep their Rust names;
data-carrying enums are `#[serde(tag = "type")]` with unit or struct variants only.

## How to add

- **A command**: `#[tauri::command] #[specta::specta]` fn in `src-tauri/src/commands/<domain>.rs`, register it in
  `specta::builder()` (`src-tauri/src/specta.rs`), run `npm run bindings`. Validate every id with its newtype's
  `parse` and canonicalise every path before use. Long work streams over a `Channel`.
- **An event**: a struct in `src-tauri/src/events.rs` deriving `Clone, Serialize, specta::Type, tauri_specta::Event`
  with a kebab-case name, register it in `specta::builder()`, run `npm run bindings`.
- **A feature**: `src/features/<name>/` with `components/`, `store.ts` (built with `createStore`), `types.ts` and
  `index.ts`, the feature's only public surface.
- **A primitive**: `src/components/ui/<Name>.tsx`, its test, a barrel and `PRIMITIVES` entry, and an example page
  `src/dev/primitives/pages/<Name>Page.tsx` registered in `registry.ts`.
- **A ⌘ chord**: an entry in `KEYMAP` (`src/lib/keyboard.ts`) and a `registerHandler` call. The native menu
  (`src-tauri/src/menu.rs`) must not claim the chord; its test reads the keymap.
- **A migration**: `crates/teamcode-core/migrations/00NN_<name>.sql` (NN = owning plan) and one line in
  `db::MIGRATIONS`. Never edit an applied migration.

`cargo test --workspace`, clippy and `npm run build` in CI. Never commit with `--no-verify`.
